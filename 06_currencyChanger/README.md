# 💱 Currency Converter App

A sleek, responsive **Currency Converter** built with **React.js**, leveraging live exchange rate data from the [@fawazahmed0/currency-api](https://github.com/fawazahmed0/currency-api).  
The app allows you to convert between currencies, swap source and target currencies, and view results instantly.

## 🛠 Features

- 🔁 Convert from one currency to another using real-time exchange rates
- 🔄 Swap between selected currencies
- 🔍 Choose from a wide list of currencies via dropdowns
- 📱 Responsive design: optimized for both desktop and mobile
- 🎨 Clean and modern UI using **Tailwind CSS**
